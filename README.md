## Overview

ARB12 addresses geographic and semantic biases in urban street-view semantic segmentation, with a particular focus on **Arab cities**.

The project introduces an annotation and taxonomy-mapping pipeline designed to improve the representation of urban scenes from Arab cities and facilitate their use with established semantic-segmentation frameworks.

The repository contains the resources associated with the ARB12 dataset and the experiments presented in the paper.
